Reviewer 1

# Paper Summary

The paper proposes "MOLT_" a training-free_ overlap-based tracking-by-detection (TBD) framework which distinguishes between two scenarios: S1 (low relative object motion_ high global deformation) and S2 (high relative object motion). 
The core contribution is a graph-based "conflict resolution" algorithm that rectifies topology (splits/merges) after registering frames via affine or deformable registration. 
Of note is that S2 type tracking requires labeled masks with no touching pixels (i.e. separation between entities) and that all deformable frame registration is performed against the first frame.

# Paper Strengths

Authors package their software in a Python package for ease of deployment and use by practitioners.

The training-free design of the algorithm can enhance overall robustness_ provided its accompanied by a well documented set of hyper-parameters/configuration which control the algorithm behavior.

Method addresses tracking by leveraging separation of concerns_ focusing only on tracking post mask creation to enable the end user to select whatever segmentation algorithm is appropriate and best performing for their situation.

Authors explicitly handle external registration artifacts between the camera and the sample_ going above and beyond the traditional approach of assuming the camera/sample pair is fixed relative to each other.

# Paper Weaknesses

Paper lacks any comparison to other tracking algorithms; either TBD or E2E despite many of the cited related works referencing many software libraries which can perform this task. Without comparison readers have no ability to understand how well this approach works in comparison to what already exists. Without comparing against standard baselines (e.g._ TrackMate_ MaMuT_ or Cell Tracking Challenge leaders)_ it is impossible to know if MOLT’s performance (IDF1 ~99%) is actually good for these specific datasets or if the datasets are simply trivial.

While broadly lacking any E2E algorithm comparisons_ there is a stark absence of comparison between specialist models (like the proposed work) and generalist models like SAM3.The current zeitgeist is a tension between narrowly scoped specialist methods which are more accurate within scope_ and the broad generalist models.Understanding how this work fits within that framework would add context.

The evaluation presented in the paper leverages silver ground truth annotations from 3 other publications.These annotations represent a clean and high quality mask to work from.Tracking by detection needs to handle segmentation failures upstream of the tracker (i.e. jitter_ fragmentation_ missed detections_ spurious detections)_ something which is missing from the data used to evaluate the method.The basically perfect detection masks being used to evaluate the method only proves that the graph based logic for identity collision resolution is correct for the studied cases.Its uncertain how well the tool would track real world data with upstream segmentation errors.Measuring tracking performance against actual segmentation algorithm output instead of ground truth masks would measure this capability.While not a primary concern of a tracking algorithm_ any robust tracking algorithm needs to handle the actual use case it will be deployed for. One cannot assume perfect input data.

S1 tracking results are qualitative only. Preparing a small manually validated dataset for this evaluation is needed to move beyond a visual inspection spot check.Additionally_ given Figure 4_ once affine alignment is done the tracking objects appear to be very well separated_ indicating a trivial tracking problem that many algorithms would be able to solve.

Affine registration of the frames is performed against frame0_ instead of maintaining a difference from the prior time frame.The tracking logic could be more robust if registration occurs between each pair of frames which would allow for pairwise union maps_ but without the increasing distortion from frame0 introducing additional error.Evaluating the difference in performance between those two approaches to justify the selection the algorithm made would support the paper.With the authors highlighting the longitudinal nature of the S1 type data_ the longer the timeframe the data spans the more mis-alignment and variance which can accumulate.Additionally_ the manuscript does not characterize the level of inter-frame distortion the registration step can handle before tracking results degrade.Characterization of the frame0 alignment accuracy delta is required for why t->0 is used instead of t-> t-1.

Authors should defend the selection of "morphological event detection" over more traditional detection accuracy metrics like those used in the cited Cell Tracking Challenge. For example_ the traditional split between detection accuracy and tracking accuracy.

Citation [4] "Merchant_ F._ Castleman_ K.: Microscope Image Processing" needs to have its missing information filled in.

Reviewer 2

Bausch et al. propose an overlap- and linage-based algorithm to track shapes moving and appearing in a dynamic environment (S1) or moving_ deforming and splitting over time in a stable environment (S2). This may be a powerful addition to the current library of tracking approaches_ including E2E neural networks_ linear assignment problem trackers_ and Kalman filter techniques_ but I find it difficult to assess this algorithm’s benefits using the information provided in this paper as there is no qualitative or quantitative comparison made to other approaches. I did not find it clear how the ability of this algorithm to work with multiple types of images is specifically a result of the proposed method. It seems this is fundamentally due to the algorithm working with already segmented objects_ which is not a main point of development and should be a shared trait of the post-segmentation pipeline of any of the TBD algorithms mentioned. To clarify the authors’ claims_ it would be helpful to have a quantitative demonstration of a single algorithm_ e.g. reference 21_ performing well on S1_ but poorly on S2_ and vice versa with another referenced algorithm_ and a comparison to the performance of this paper’s algorithm on both tasks. I think this algorithm has additional benefits that are worth highlighting_ such as assigning provenance to multiple cells splitting from a single cell. I encourage the authors to revise this manuscript to make a clearer argument for the benefits of their algorithm and provide quantitative results backing these claims.
Quantitative comparisons should use a consistent set of metrics comparing this paper’s algorithm performance to that of the other algorithms mentioned in this paper on identical data sets. The authors may consider swapping their IDF1 metric for any of the AMI_ NMI_ P@1_ RP_ or MAP@R metrics used in reference 11. Similarly_ the authors could benchmark performance of their algorithm on Fluo-N3DH-SIM+_ which is used in reference 11_ instead of Fluo-N2DH-GOWT1. Using the same data set from the Cell Tracking Challenge and the same metric as reference 11 would provide a direct comparison of this algorithm’s performance to reference 11. This logic should be extended to test this algorithm’s performance against all the algorithms mentioned in this paper. I would also recommend comparing the performance of this algorithm to those used in TrackMate (https://www.nature.com/articles/s41592-022-01507-1)_ which is included in ImageJ and is a popular tool for biologists interested in tracking cells. TrackMate is not domain specific and therefore would be a good comparison to this paper’s approach.
In the background section_ it’s not clear to me how the discussion of TBD vs. E2E algorithms contributes to the understanding of the importance of this paper’s technique. E2E algorithms are criticized for being domain specific. Is it not possible to re-train these neural networks on other image types? Are they truly fixed in their domain_ or just inconvenient to use? Is the goal of this paper to demonstrate that this algorithm is easier to use and more flexible than neural network E2E algorithms? If so_ then a comparison of speed of retraining and applying an E2E approach vs. direct application of this technique should be included in the results section of this paper. If a specific E2E algorithm can only be used for task S1 or task S2_ this should be stated.
The claim in the conclusion section that this method has robust performance is not sufficiently supported by the experiments in the paper. Please test this algorithm on a more comprehensive and diverse set of images to establish this or soften the claim.
Minor points 
In the background section_ there’s a detailed discussion of E2E vs. TBD and how the different algorithms work_ including such details as mentioning reference [20]’s thresholding and Watershed algorithm_ even though this paper’s algorithm does not focus on segmentation. I was not clear to me how these points tie into the main points of the paper_ as they do not come up again in methods or results. Perhaps the background section could be reworked to be more focused on relevant details.
Table 1 compares affine and deformable registrations_ but there is limited discussion of deformable registration before this_ and no discussion of deformable registration in the methods. Given this_ and that the deformable registration categorically performs worse than the affine registration according to this table_ I would drop deformable registration from the manuscript entirely.
The lower end of the range of the accuracy percentages and IDF1 scores mentioned in “Results on S2” do not appear in Table 1_ despite the text stating that they do. Please update.
It’s hard to follow the difference between the linage and tracked images included in “visuals.zip”. It would helpful if the authors could identify what information the reader is supposed to glean from each animation and perhaps include a section of the video where we zoom in on a single cell dividing over time and watch how the lineage vs. track images change over a short period of time in a small ROI. It would also help if we could see these images as part of a tryptic: the original image_ the lineage image_ and the track image all next to one another and moving together in a single video. 


Reviewer 3

The authors describe a training-free tracking by detection post-processing framework for multi-object and lineage tracking in 2D and 3D biomedical time-series. The method combines image registration with an overlap-based association built from a union-map (logical union of aligned instance masks)_ followed by a graph-based conflict resolution step that converts potentially conflicting union associations into unique lineage identifiers_ and then propagates temporally consistent tracked IDs along the resulting graphs. Two tracking scenarios are defined: S1 aligns all frames to the first frame to handle strong ROI misalignment_ and S2 performs pairwise registration to the preceding frame to support strong relative motion. The paper evaluates S1 qualitatively on 3D beta-amyloid plaque tracking and S2 quantitatively on 2D cell-tracking challenge datasets. Comments:

The strongest technical contribution is the graph-based conflict resolution that maps conflicting union associations to unique lineage IDs (connected groups)_ addressing splits caused by registration and nearest-neighbor interpolation. Make this the headline novelty and distinguish it from earlier overlap-based trackers.
You explicitly use binarized ground-truth segmentations as input and note that false positives do not exist in this evaluation. This is fine_ but it must be stated as a limitation. If possible_ add one experiment using automated segmentations to demonstrate robustness to realistic errors.
You use Greedy registration computed on raw microscopy images and apply transforms to segmentations with nearest-neighbor interpolation_ and you state performance depends strongly on registration accuracy. Please report the key registration settings.
The paper defines positive as no event and negative as event present_ and true/false based on matching the number of children between prediction and ground truth. This is workable_ but the naming is easy to misread. Consider renaming or adding a short explanation up front.
You state cell-tracking data comes from the Cell Tracking Challenge and the beta-amyloid dataset will be available within 12 months. Consider whether you can release a subset or derived artifacts earlier to support reproducibility expectations.

Reviewer 4:

Summary: The authors present MOLT_ a training-free multi-object tracking framework for biomedical time-series that uses a "Union Map" and graph-based conflict resolution. The method is evaluated on 3D Beta-amyloid images and 2D cell tracking datasets. While the tool is a potentially useful resource for training-free tracking_ the reporting of results lacks statistical depth_ and specific limitations are understated.
Recommendation: Major Revisions Required

Revisions required:
Statistical Reporting: Please report the standard deviation or variance alongside the mean values for Accuracy and IDF1 in Table 1 to demonstrate the stability of the method across different datasets or ROIs.
Benchmark Comparison: For improved context and transparency within the Tracking-by-Detection (TBD) paradigm_ the authors should consider including in Table 1 a comparison against a standard_ training-free TBD baseline (e.g._ Hungarian linking or Track Mate)_ instead of restricting the comparison to internal variants.
Ground Truth Bias: The evaluation uses binarized ground truth segmentations_ which eliminates segmentation noise inherent in real-world data. Please explicitly discuss this bias and how imperfect input segmentations would affect the "Union Map" and conflict resolution steps.
S2 Limitations: Please rewrite the Abstract and Conclusion to explicitly state the limitation that the method cannot handle object disappearance or reappearance in Scenario 2_ as the current claims of robustness are overstated.
Registration Dependency: Please explicitly describe potential failure modes of the registration step and how registration errors propagate to downstream lineage tracking_ as the method’s performance depends on the accuracy of the underlying registration algorithm. 
Metric Definition: While the manuscript defines positive and negative cases for the “morphological detection accuracy” metric_ it does not explicitly state how these quantities are combined into a final accuracy. Please provide a formula or equation to clarify this and to support an accurate interpretation of the reported values.
